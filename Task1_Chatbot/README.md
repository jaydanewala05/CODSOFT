# Task 1: Rule-Based E-Commerce Chatbot

## 📝 Description
A rule-based e-commerce chatbot that responds to user inputs based on predefined rules using pattern matching techniques. The chatbot assists customers with:
- Order tracking
- Product information & pricing
- Stock availability
- Shipping & return policies
- Customer support

## 🛠️ Technologies Used
- HTML5
- CSS3 (Modern design with animations)
- JavaScript (Pure JS - No frameworks)
- Font Awesome Icons

## ✨ Features
- **Pattern Matching**: Uses regex and keyword matching for intent recognition
- **Modern UI**: Glass-morphism design with animations and responsive layout
- **No Backend Required**: Pure frontend solution
- **Session Management**: Tracks conversation context
- **Suggestion Chips**: Quick access to common queries
- **Typing Indicator**: Realistic bot response simulation

## 🚀 How to Run

### Method 1: Direct Open
1. Download/Task1_Chatbot/index.html
2. Double-click to open in any modern browser

### Method 2: VS Code with Live Server
1. Open folder in VS Code
2. Install "Live Server" extension
3. Right-click index.html → "Open with Live Server"
